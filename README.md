# ☕ Starbucks Brewing Insights Dashboard

## 📊 Project Overview

The **Starbucks Brewing Insights Dashboard** is a data visualization project created to analyze Starbucks beverages based on nutritional information and beverage categories.

The dashboard provides a simple and interactive way to understand beverage characteristics such as **Calories, Sugar, Protein**, and the distribution of different beverage categories.

---

## 🎯 Project Objectives

- Analyze Starbucks beverage nutritional data.
- Compare average calories across beverage categories.
- Compare average protein across beverage categories.
- Understand the distribution of beverages by category.
- Identify beverages with high total calorie values.
- Present important insights using an interactive dashboard.

---

## 📌 Dashboard Highlights

The dashboard contains the following key metrics:

| KPI | Value |
|---|---:|
| Total Beverages | 33 |
| Average Sugar | 33.02 |
| Average Calories | 194.30 |
| Average Protein | 7.00 |

---

## 📈 Visualizations

The dashboard includes:

### 1. Average Calories by Beverage Category
Shows the average calorie level for different Starbucks beverage categories.

### 2. Average Protein by Beverage Category
Compares the average protein content across beverage categories.

### 3. Beverage Category Distribution
Shows how the 33 beverages are distributed among different beverage categories.

### 4. Total Beverages by Category
A donut chart representing the number and percentage of beverages in each category.

### 5. Sum of Calories by Beverage
A horizontal bar chart comparing the total calories of beverages.

## 📊 Key Insights

- The dashboard analyzes a total of **33 beverages**.

- The average sugar content is approximately **33.02**.
